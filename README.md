# Adorable Interior website

A polished, responsive landing page for Adorable Interior — quality and affordable furniture, home furnishing and interior decoration in Lagos, Ibadan and Abuja.

## Included
- Responsive luxury furniture storefront design
- WhatsApp ordering and inspection booking CTAs
- Furniture collection and service sections
- Pricing tiers and social proof
- Mobile navigation and scroll reveal animations

## Run locally
Open `index.html` in a browser. No build step is required.

## Replace later
Update the image URLs in `index.html` with Adorable Interior's own product photography when available.
